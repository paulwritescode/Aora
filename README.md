# Aora - Premium Beauty Collection

A modern, responsive e-commerce website showcasing Maybelline's premium beauty products. Built with React, TypeScript, and Tailwind CSS.

## ✨ Features

- **Modern Hero Section** - Engaging landing page with gradient backgrounds and animations
- **Interactive Product Carousel** - Showcases featured products with smooth transitions
- **Advanced Product Grid** - Responsive grid with search, filtering, and view modes
- **Enhanced Product Cards** - Beautiful cards with hover effects, ratings, and wishlist functionality
- **Dark/Light Theme** - Toggle between themes with smooth transitions
- **Responsive Design** - Mobile-first approach that works on all devices
- **Smooth Animations** - Powered by Framer Motion for delightful user experience

## 🚀 Tech Stack

- **React 18** - Modern React with hooks and functional components
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework
- **Radix UI** - Accessible component primitives
- **Framer Motion** - Animation library
- **React Router** - Client-side routing
- **Axios** - HTTP client for API requests

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 📊 Data Source

- Product names and descriptions
- High-quality product images
- Pricing information
- Product categories and types
